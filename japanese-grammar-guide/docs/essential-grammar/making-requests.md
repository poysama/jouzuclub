# Making Requests

{: .fs-9 }

There are many levels of politeness when asking for things in Japanese.
{: .fs-6 .fw-300 }

## 1. ~Te kudasai (Standard Polite)

Standard request. "Please do..."
_食べてください。(Tabete kudasai.)_ (Please eat.)

## 2. ~Te choudai (Casual / Feminine)

Similar to kudasai but more casual.
_待ってちょうだい。(Matte choudai.)_ (Wait up.)

## 3. ~Nasai (Command / Authoritative)

Used by parents to children or teachers to students.
_食べなさい。(Tabenasai.)_ (Eat it.)

## 4. ~Shiro / ~Ro (Strong Command)

Very rough, used by men or in emergencies.
_食べろ！(Tabero!)_ (Eat!)

## Asking for Permission (Mo ii desu ka?)

Structure: `Te-form` + `mo` + `ii` (good) + `desu ka`?
_食べてもいいですか？(Tabete mo ii desu ka?)_\n(Is it okay if I eat? / May I eat?)
