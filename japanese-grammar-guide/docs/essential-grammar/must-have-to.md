# Must / Have to

{: .fs-9 }

There is no single word for "must" in Japanese. Instead, you use a double negative phrase that literally means "If I don't do X, it won't be good."
{: .fs-6 .fw-300 }

## Structure 1: Nakereba naranai

The most formal and standard way.

1.  Conjugate to Negative (`nai` form).
2.  Drop `i` and add `kereba` (conditional).
3.  Add `naranai` (will not become/be good).

_Taberu_ (食べる) → _Tabenai_ (食べない) → _Tabenakereba naranai_ (食べなければならない)\n(Must eat.)

## Structure 2: Nakute wa ikenai

Slightly less formal, "It cannot go if I don't..."
_食べなくてはいけない。(Tabenakute wa ikenai.)_

## Casual Abbreviations

In speech, these long phrases are shortened.

- **Nakucha** (from _nakute wa_)
- **Nakya** (from _nakereba_)

_もう行かなくちゃ。(Mou ikanakucha.)_ (I gotta go already.)
