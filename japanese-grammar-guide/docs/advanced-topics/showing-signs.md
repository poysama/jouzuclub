# Showing Signs

{: .fs-9 }

Describing appearances or vibes.
{: .fs-6 .fw-300 }

## Meku (To show signs of...)

Noun + `meku`. Behaving like or showing signs of that noun.
_春めいてきた。(Haru meite kita.)_\n(It has started to become spring-like.)\n*謎めいた行動。(Nazo meita koudou.)*\n(Riddle-like / Enigmatic behavior.)

## Buru (To act like...)

Pretending to be something.
_大人ぶる。(Otona-buru.)_\n(Acting like an adult.)\n*モブリ。(Moburi.)* (Mogul-pretender [Slang])
