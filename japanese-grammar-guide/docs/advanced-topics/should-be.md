# Things that "Should be"

{: .fs-9 }

Expressing expectation or obligation that is logical or moral.
{: .fs-6 .fw-300 }

## Hazu (Expectation)

"It is supposed to be..." based on calculation or logic.
_彼はもう着いたはずだ。(Kare wa mou tsuita hazu da.)_\n(He should have arrived by now [logically].)

## Beki (Moral Obligation)

"One should..." based on duty or morals.
_約束は守るべきだ。(Yakusoku wa mamoru beki da.)_\n(One should keep promises.)\n*人を傷つけるべきではない。(Hito wo kizutsukeru beki de wa nai.)*\n(One should not hurt others.)
