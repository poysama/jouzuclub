# Similarity and Hearsay

{: .fs-9 }

How to say something looks like or seems like something else.
{: .fs-6 .fw-300 }

## You (Seems/Likeness)

Nouns/Verbs behave like Nouns.
_あの人は田中さんのようだ。(Ano hito wa Tanaka-san no you da.)_ (That person looks like/seems like Tanaka-san.)

## Mitai (Casual "You")

More colloquial.
_田中さんみたいだ。(Tanaka-san mitai da.)_ (Looks like Tanaka-san.)

## Sou (Looks like / Hearsay)

### Looks Like (Stem + Sou)

_おいしそう。(Oishisou.)_ (Looks delicious.)\n*雨が降りそう。(Ame ga furisou.)* (Looks like rain.)

### Hearsay (Plain + Sou)

_おいしいそう。(Oishii sou.)_ (I heard it is delicious.)\n*雨が降るそう。(Ame ga furu sou.)* (I heard it will rain.)
