# Honorific and Humble Forms

{: .fs-9 }

Keigo (Honorifics) is split into two main categories: **Sonkeigo** (Honorific) and **Kenjougo** (Humble).
{: .fs-6 .fw-300 }

## Sonkeigo (Honorific)

Used to describe the actions of **superiors** or customers. Elevates the subject.

### Regular Formation

`O` + `Verb Stem` + `ni naru`.
_先生がお読みになる。(Sensei ga o-yomi ni naru.)_ (The teacher reads.)

### Special Verbs

- _Iku/Kuru/Iru_ (行く/来る/いる) → **Irassharu (いらっしゃる)**\n- _Taberu/Nomu_ (食べる/飲む) → **Meshiagaru (召し上がる)**\n- _Suru_ (する) → **Nasaru (なさる)**\n- _Miru_ (見る) → **Goran ni naru (ご覧になる)**

## Kenjougo (Humble)

Used to describe **your own** actions when speaking to a superior. Lowers yourself.

### Regular Formation

`O` + `Verb Stem` + `suru`.
_私がお持ちします。(Watashi ga o-mochi shimasu.)_ (I will hold it.)

### Special Verbs

- _Iku/Kuru_ (行く/来る) → **Mairu (参る)**\n- _Iru_ (いる) → **Oru (おる)**\n- _Suru_ (する) → **Itasu (致す)**\n- _Taberu/Nomu_ (食べる/飲む) → **Itadaku (いただく)**
