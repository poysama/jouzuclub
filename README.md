# Tae Kim's Japanese Grammar Guide - Quick Reference

This is a static documentation website for Tae Kim's Japanese Grammar Guide, built with [Jekyll](https://jekyllrb.com/) and the [Just the Docs](https://just-the-docs.com/) theme.

## Setup

1.  **Install Ruby and Bundler**: Ensure you have a Ruby development environment installed.
2.  **Install Dependencies**:
    ```bash
    bundle install
    ```
3.  **Run Locally**:
    ```bash
    bundle exec jekyll serve
    ```
    The site will be available at `http://localhost:4000/nihongobanzai/`.

## Deployment

This site is ready to be deployed to GitHub Pages.

1.  Push the repository to GitHub.
2.  Go to Settings > Pages.
3.  Select the branch (e.g., `main` or `master`) and folder (usually `/ (root)`).
4.  Your site will be live at `https://<username>.github.io/nihongobanzai/`.

## Structure

- `_config.yml`: Site configuration.
- `docs/`: Contains the markdown source files for the guide, organized by chapter.
