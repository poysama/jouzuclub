# The Te-form

{: .fs-9 }

The te-form (て-form) is an incredibly versatile conjugation used for connecting sentences, making requests, and present progressive actions.
{: .fs-6 .fw-300 }

## Conjugation rules

The rules are exactly the same as the **Past Tense (Ta-form)**, but you replace `ta` with `te` and `da` with `de`.

### Examples

- `Taberu` (食べる) → `Tabeta` (食べた) → **`Tabete` (食べて)**\n- `Nomu` (飲む) → `Nonda` (飲んだ) → **`Nonde` (飲んで)**\n- `Suru` (する) → `Shita` (した) → **`Shite` (して)**

## Common Usages

### 1. Sequence of Events

_昼ご飯を食べて、寝る。(Hiru-gohan wo tabete, neru.)_\n(Eat lunch, and then sleep.)

### 2. Requests (Please do...)

Add `kudasai` after the te-form.
_来てください。(Kite kudasai.)_\n(Please come.)

### 3. Present Progressive (Doing...)

Add `iru` after the te-form.
_食べている。(Tabete iru.)_\n(Am eating.)
