# Introduction to Particles

{: .fs-9 }

Particles are small suffixes that follow a word to define its grammatical function in the sentence.
{: .fs-6 .fw-300 }

## The Topic Particle "Wa" (は)

The particle `wa` (written as `ha` but pronounced `wa`) identifies the **topic** of the sentence.

### Example

```text
私は学生だ。\n(Watashi wa gakusei da.) - As for me, I am a student.
```

## The Subject Particle "Ga" (が)

The particle `ga` identifies the specific **subject** that is performing the action or state.

### Example

```text
誰が来ましたか？\n(Dare ga kimashita ka?) - Who came?
```

## The Object Particle "Wo" (を)

The particle `wo` (pronounced `o`) marks the direct object of a verb—the thing that is being acted upon.

### Example

```text
本を読む。\n(Hon wo yomu.) - Read a book.
```

## The Target/Direction Particle "Ni" (に)

The particle `ni` indicates a target location, time, or movement towards something.

### Example

```text
学校に行く。\n(Gakkou ni iku.) - Go to school.
```

## The Direction Particle "He" (へ)

Pronounced `e`, this particle is vaguely similar to `ni` but emphasizes direction rather than the destination itself.

### Example

```text
日本へ行く。\n(Nihon he iku.) - Go towards/to Japan.
```
