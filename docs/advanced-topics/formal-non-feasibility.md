# Formal Non-feasibility

{: .fs-9 }

Advanced ways to say "Cannot" or "Must".
{: .fs-6 .fw-300 }

## Zaru wo Enai (Cannot help but...)

"It is not possible to not do..." -> "I have to do it."
Structure: Negative stem + `zaru wo enai`.
_やるざるを得ない。(Yaruzaru wo enai.)_\n(I have no choice but to do it.)

## Yamu wo Enai (Unavoidable)

"It is unavoidable."
_やむを得ない事情で... (Yamu wo enai jijou de...)_\n(Due to unavoidable circumstances...)
