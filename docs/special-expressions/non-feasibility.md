# Non-feasibility (~You ga nai)

{: .fs-9 }

Used to express that there is **no way** to do something, usually due to lack of means.
{: .fs-6 .fw-300 }

## Structure

`Verb Stem` + `you` + `ga` + `nai`.

## Examples

_直してあげたいが、直しようがない。(Naoshite agetai ga, naoshiyou ga nai.)_\n(I want to fix it for you, but there is no way to fix it.)\n\n*ここまで来たら、戻りようがない。(Koko made kitara, modoriyou ga nai.)*\n(Since we came this far, there is no way to go back.)
