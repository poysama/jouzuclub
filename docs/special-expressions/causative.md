# Causative Form

{: .fs-9 }

The causative form expresses **making** or **letting** someone do something.
{: .fs-6 .fw-300 }

## Conjugation

### Ru-verbs

Drop `ru` and add `saseru`.
_Taberu_ (食べる) → _Tabesaseru_ (食べさせる) (Make/Let eat)

### U-verbs

Change final /u/ to /a/ and add `seru`.
_Iku_ (行く) → _Ikaseru_ (行かせる) (Make/Let go)\n*Matsu* (待つ) → _Mataseru_ (待たせる) (Make wait)

### Irregular

- **Suru (する)** → **Saseru (させる)**\n- **Kuru (来る)** → **Kosaseru (来させる)**

## Usage

_先生は学生に宿題をさせた。(Sensei wa gakusei ni shukudai wo saseta.)_\n(The teacher made the student do homework.)\n\n*私にやらせてください。(Watashi ni yarasete kudasai.)*\n(Please let me do it.)
