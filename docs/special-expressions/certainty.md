# Expressing Certainty

{: .fs-9 }

Ranging from "maybe" to "definitely".
{: .fs-6 .fw-300 }

## Kamoshirenai (Might/Maybe)

Asserts a possibility (approx 50% or less). Append directly to plain forms.
_明日は雨かもしれない。(Ashita wa ame kamoshirenai.)_ (It might be rain tomorrow.)\n*行くかもしれない。(Iku kamoshirenai.)* (I might go.)\n*Casual: かも。(Kamo.)*

## Nichigainai (Must be / No doubt)

High certainty logic deduction.
_あれは田中さんに違いない。(Are wa Tanaka-san ni chigainai.)_ (That must be Tanaka-san.)

## Deshou / Darou (Probably)

High probability.
_明日は雨でしょう。(Ashita wa ame deshou.)_ (It will probably rain tomorrow.)
